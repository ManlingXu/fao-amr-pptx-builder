# 用全库录一段 AMR 简报对话

从全库准备一份十页简报。观众能看到你输入需求、助手追问页数、逐页给出出处、按你的指示修改方案，最后交付 PowerPoint。录屏前先完成首次资料下载。

## 录屏前启动

1. 下载最新版源码 ZIP，全部解压到“下载”里的 `AMR-Recording` 文件夹。保留原工程，以便启动器复用已经下载的课件。[下载 GitHub 主分支 ZIP](https://github.com/ManlingXu/fao-amr-pptx-builder/archive/refs/heads/main.zip)
2. 在新工程中双击 `start-amr.cmd`，或在 PowerShell 中逐行执行下列命令。无参数启动会准备正式 AMR 全库。首次运行需要联网。

```powershell
$demo = Join-Path $env:USERPROFILE "Downloads\AMR-Recording"
$start = Get-ChildItem $demo -Filter start-amr.cmd -File -Recurse | Select-Object -First 1
Set-Location $start.DirectoryName
.\start-amr.cmd
```

3. 服务启动后保留 PowerShell 窗口，在浏览器打开 <http://127.0.0.1:8765>。先看全库资料数。正式目录收录 184 份，可检索数取决于本机实际校验成功的文件。以前的七份 UK-VARSS 课件是可单独运行的小样本。若仍看到七份，请关掉旧服务，从新工程不带参数启动。
4. 事先准备一套带有母版样式的 `.pptx` 或 `.potx`，文件不超过 16 MiB。录制时可选用配套的 `Recording_Template.pptx`。使用默认本地索引即可完成下面的对话。如果要演示已安装的 Ollama 模型，先展开“检索模式”并填入本机的模型名称。[Windows 操作与模型设置](LOCAL_AMR_DEMO_CN.md)

## 开始录屏

本次试录中，程序在 182 份已校验课件的 4,676 页中检索，返回的 10 页来自 10 份原始课件。调整页序后，导出清单的第 1 页与刚移动的原第 3 项一致。套用第二个模板后，10 页的来源备注均保留。你录制时以本机显示的实际数为准，每次在同一个对话框中发一条。

| 你输入 | 镜头停在哪里 |
| --- | --- |
| 主题是畜牧业抗菌药物使用、养殖户培训和耐药监测 | 助手收到主题，向你询问页数。 |
| 10页 | 在“页序与来源”展开一页，看原始课件、原页码和证据摘录。区分参与检索的课件数和实际入选的课件数。 |
| 为什么选第2页 | 助手解释这页和问题的关系。点“打开原始来源”可看发布机构的页面。 |
| 把第3页移到第1页 | 展示更新后的第一项和总页数。 |
| 确认生成 | 点“下载初稿”。在 PowerPoint 打开第一张的备注，核对它和刚才确认的第一项。 |
| 换模板 | 上传模板，点“应用模板”，再点“下载新模板版”。让两个版本停在同一页，对照母版和备注中的出处。 |

如果你想演示某一国家，可另开“新对话”，输入“主题是赞比亚兽医抗菌药物管理、国家行动计划、养殖户培训和动物监测”，收到追问后输入“10页”。检索仍从当前加载的全库出发。证据不足时，按助手列出的实际页数决定是否调整主题或导出。
